* Libraries:

--> Using our own functions in other files:
    - when we are trying to use our own function in other files, we might take care of the main() function caller from the original file with our function implementation since 
      when importing the file from where our function is (e.g. 'from sayings import hello'), if we do not manage the main() function caller correctly, we might be calling the whole program rather than only using its desired function implementation,
    - therefore, we need to use the technique:
        if __name__ == "__main__":
            main()
    - in this way, calling the whole main() function is ignored, so that using only the funcitonality from the imported function implementation.
