* print() function from documentation:

    print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)

    - *objects --> print() can receive multiple arguments:
        ~ e.g.: print("Hello", "Julio", 19)
        ~ * --> "accept many values".

    - sep=' ' --> sep means separator OR ' ',
        ~ e.g.: print("Hello", "Julio")
        ~ Output: Hello Julio
        ~ Output Explanation: Python inserts the separator between arguments.
        ~ therefore, sep='...' allows to change the separation to the contents in our arguments' outputs
        ~ If you want to use sep, you MUST PASS MULTIPLE ARGUMENTS separated by commas.

    - end='\n' --> what gets printed at the end automatically adds a newline
        ~ in fact, adding end="" in our print arguments will avoid doing a default line jump
        ~ therefore, end="..." allows to add certain line comment/behavior at the end of our print() function

    - file=sys.stdout --> destination where the output goes (standard output stream)
        ~ Meaning: send output to the normal console output stream
        ~ Similar to java's System.out
        ~ sys ≈ System
        ~ stdout ≈ out

    - flush=False --> Python waits a little before forcing output to appear.
        ~ 

* Conclusion about the print() function:
    #print(*objects) can print multiple arguments separated by sep and ending with end.


--> Note: keyword argument could not be repeated!!
    - "*objects, sep=' ', end='\n', file=sys.stdout, flush=False" are keyword parameters!

--> Note: Python allows both single quotes (' ') and double quotes (" ") for strings
        ~ In the case of "print('I'm Julio')", python will escape because there is an apostrophe ' inside the string.
        ~ In "print("I'm Julio")", Python works without escaping.
