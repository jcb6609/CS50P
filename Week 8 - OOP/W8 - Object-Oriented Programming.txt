* tuple:

    	~ e.g. (x, y)

    - Similar to a list, with the difference that a tuple is immutable (you cannot change/update the values of it)
    - We can index into it numerically: [0, 1, ..., n]
    - While trying to modify (or overwriting) on of the tuple elements, we will get back an error
    - Instead, if we want to modify/change/overwrite vars, then we would use a list, which are mutable

* class (keyword):

    - general purpose term that allows use to define custom containers with custom names for pieces of data.

    - the class's object is mutable, but we can make it ummutable

* instance method '__init__()':

    - Used to initialize (initializer) the contents of an object from a class
    - '__init__(self, var1, var2, ..., varn)' --> It sets initial values for the class object's attributes


* self:

    - Placeholder that ensures the data is written on your specific copy of the class
    - helps to store the attributes of an object creation call (an object that has just been
      instantiated) by/as a hidden argument 'self' inside of the instance method __init__() 
      therefore, giving you access to the current object that was just created
    - there is nothing in the object initially (from the constructor call), but that object
      exists in the computer's memory. It's now up to us to store those attributes inside of
      the object. How? By using the 'self' argument/convention as our object's attribute 
      reference to, again, define those object attributes since, again, there is nothing 
      inside of it.
    - In other words, 'self' is a convention to define a just instatiated object's attributes! 
    - 'self', as its name implies, gives you access to the current object that was just created/instantiated

--> the constructor (or constructor call) construct/instantiate an obj for us
--> the constructor method calls the '__init__(self, ...)' method
--> a constructor is a mehtod and NOT a function since its definition is implemented inside of a class (by calling the instance method '__init__(self, ...)')
--> the instance method allows us to implement the initialization of an object (an its attributes)
--> the constructor will automatically call the __init__() method (which is inside of the class specified by the constructor call (which has the same name as the class)), and therefore initializing the attributes (constructor arguments) of the just instantiated obj by automativally calling the instance method __init__() when using a constructor 
--> we can create an instance variable/attribute called 'self.names' that stores a list of names or a list of houses let's say
--> objects are stored in the computer's memory by taking up some numbers of bytes
